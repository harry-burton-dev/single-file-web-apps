OneDrive trace recorder

Nothing is sent anywhere. This page makes no network requests and uses no external files. All recorded data stays in this browser tab until you press "Download trace". Do not close or reload the tab before downloading.

This browser

How to use this page

  1. In File Explorer, pick or create an empty test folder inside the shared OneDrive area. Do not use a folder that holds real data.
  2. Open this page on each laptop and start recording on all of them at about the same time.
  3. Leave the page open and the laptop awake for the chosen duration.
  4. When the countdown ends, press Download trace and send the file to the person running the study.

What this page will and will not touch

This page works only inside trace-recorder/ in the folder you chose, and writes only under trace-recorder//. It never deletes or changes anything outside trace-recorder/, and it never changes other devices' folders.
